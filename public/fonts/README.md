# 研习刊局部界面字体

`journal-serif.woff2`：Noto Serif SC，字重 400–600，262 个字符，95,924 bytes（约 93.68 KiB）。

- 来源与完整用字清单：`journal-serif.source.json`；许可：`OFL.txt`（SIL OFL 1.1）。
- 从登录、外壳、今日页源码收集静态中文，另含数字和标点；修改这些静态文案后应更新子集。
- CSS 别名为 `Yanxiben Journal UI`，仅用于本轮外壳品牌和今日页的标题、数字。正文继续使用系统无衬线。
- 字体由应用同源提供，运行时不请求 Google Fonts。动态文字可回退系统衬线，未加入全量中文字库。
- 字符覆盖包含登录文案；登录页继续使用上一轮的字体与样式文件，本轮不改登录页。
