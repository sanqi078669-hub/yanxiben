# 研习刊局部界面字体

`journal-serif.woff2`：Noto Serif SC，字重 400–600，455 个字符，148,164 bytes（约 144.69 KiB）。

- 来源与完整用字清单：`journal-serif.source.json`；许可：`OFL.txt`（SIL OFL 1.1）。
- 保留原登录、外壳、今日页用字，补充资料库、详情及批量整理/分析/AI 面板静态中文，另含数字和标点；完整源码清单见来源文件。修改这些静态文案后应更新子集。
- CSS 别名为 `Yanxiben Journal UI`，用于外壳品牌及已接入研习刊的页面标题、数字。正文继续使用系统无衬线。
- 字体由应用同源提供，运行时不请求 Google Fonts。动态文字可回退系统衬线，未加入全量中文字库。
- 字符覆盖包含登录文案；登录页继续使用上一轮的字体与样式文件，本轮不改登录页。
