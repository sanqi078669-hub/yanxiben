## 实现约束

- 所有 AI 写入均需界面确认。截图识别替换标题、题面与选项；整理替换标题和总结并合并标签；错因建议追加到总结，不覆盖原作答。
- 文本助手提供发送预览；图片识别仅发送最多三张题面图。提示请求不发送参考答案、总结或原解法。
- 支持 OpenAI Chat Completions 兼容接口，配置地址、模型名称、图片能力、输出长度参数。其他协议需要后续适配，不声称所有服务原生 API 通用。
- 配置保存在 data/ai-private 中，AES-GCM 加密；密钥文件同机保存，目的是避免明文配置泄露，不等同于抵抗本机管理员访问。学习备份不包含密钥，需要另行配置。
- 真实模型输出具有不确定性，结构校验和本次样例通过不代表所有答案正确。
