# FIX-10 AI 配置与边界验收

日期：2026-10-23。本节更新代码审查后的行为；此前功能验收见 [AI-ACCEPTANCE.md](AI-ACCEPTANCE.md)。

## 输出长度与截断

设置页每个模型可选 4,000（旧配置默认）、8,000、16,000 token，沿用 max_tokens / max_completion_tokens 参数选择。服务商对模型上限的实际限制仍以其接口为准，不支持的参数返回明确服务商错误，不自动降低上限重试。等待期限随上限为 45 / 90 / 180 秒，响应仍限制 256KB。

上限进入发送目标指纹，修改后旧页面确认的目标失效。finish_reason=length 返回 AI_OUTPUT_TRUNCATED，不返回半份建议、不写入学习内容、不自动重试；已返回的 token 用量和估算费用保存在失败调用记录中。

## 目标地址

保存及发送均要求无账号、查询参数、片段的 HTTPS 地址。发送时解析全部 DNS 结果，任何非公网结果都拒绝，包括混合公网/私网记录；检查 IPv4、IPv6、回环、链路本地、保留/文档地址和 IPv4 映射。连接固定到本次检查的 IP，保留原主机名的 TLS 证书校验；不跟随重定向。DNS 等待和连接均受取消/超时控制。

官方预设仍填入官方端点；自定义公网兼容端点保留。本机模型连接不属于当前支持范围。使用 Node HTTPS 直连，不通过未校验的第二次 DNS 查找或自动重定向；没有关闭证书校验。

## 加密主密钥

- 新主密钥位于 DATA_DIR 外：默认项目 `.private-secrets/<引用ID>.key`，DATA_DIR/ai-private/key-reference 只保存引用。目录和密钥被 Git 忽略。
- 部署可设置 `AI_KEY_FILE` 指向 DATA_DIR 外的独立 32 字节主密钥文件。路径不能位于 DATA_DIR 内；该变量是文件路径，不是服务商 API Key。生产环境应通过私有部署文件提供，不写进代码或日志。
- 首次读取旧配置时，验证旧 encryption-key 能解开现存全部密文，再独占创建新文件，回读比对并验证后才删除旧文件。中途失败保留原文件；冲突密钥不覆盖。
- 密钥缺失且仍有旧密文时返回 AI_KEY_UNAVAILABLE，不生成新密钥冒充原密钥。恢复独立主密钥，或移除旧配置后重新填写服务商密钥；多个账号共用主密钥时应处理全部旧密文。
- 学习 ZIP 不包含模型凭据或主密钥。只迁移 DATA_DIR、只备份数据库或重新恢复学习 ZIP，均不能代替独立保存 AI 主密钥。默认路径下移动整个项目时需一起保留私有目录；指定路径时另行保管该文件。
- Next 生产文件追踪显式排除私有数据、测试产物、主密钥及环境文件；构建结束检查全部服务端追踪清单，包含私有运行文件则拒绝交付。修复前检查确实发现这些路径被追踪，修复后构建检查及无开发依赖生产恢复均通过；未发布旧产物。

没有引入 Windows DPAPI：当前还有 CLI、独立恢复进程和跨目录生产安装流程，采用独立文件保持这些流程一致。此措施避免“复制 DATA_DIR 即获得密钥”，不抵抗可以同时读取项目私有目录和数据目录的本机管理员。项目整体仍需保持私有。

## 每日调用与费用

每账号默认每日 100 次，可在设置改为 1–10,000 次。按用户学习时区计算日期；发送尝试（含失败、连接测试）在事务中预留并持久化，跨服务进程也共用计数及单账号活动请求记录。正常结束释放活动状态；异常退出后最多等待 240 秒，不因重启清零当天计数。未知/崩溃请求保留未知费用。

费用阈值可不启用；启用时必须有当前模型/主机/币种匹配的单价。请求使用开始时的价格快照，返回用量后结算。达到阈值后停止后续调用；**单次请求可能超过剩余额度，此功能不是服务商硬额度**。当天有未知费用时阻止受费用阈值保护的新调用，不能将未知价格或未知用量计为零。跨币种不自动换算。

并发预算检查在 SQLite 事务中执行；没有因失败自动重发。所有费用均为本地估算，缓存优惠、实际服务商规则及最终扣费以服务商账单为准。日计数/活动状态是本机运行记录，不随学习 ZIP 导出；恢复到独立空间会重新计数，不能代表服务商当天总用量。
